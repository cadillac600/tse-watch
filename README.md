# 📊 東証 上場維持基準 監視サイト

2025年3月から厳格化された東証の上場維持基準に注意が必要な銘柄を毎日自動抽出・公開するサイトです。

🌐 **公開サイト**: https://あなたのGitHubユーザー名.github.io/tse-watch/

---

## 監視している基準

| 市場 | 流通株式時価総額 |
|------|----------------|
| プライム | 100億円以上 |
| スタンダード | 10億円以上 |
| グロース | 5億円以上（＋上場10年で40億円以上） |

> **注意**: 表示される時価総額は「会社全体の時価総額」の推定値です。
> 上場維持基準の「流通株式時価総額」とは異なります（流通株式比率30%と仮定した目安）。

## 仕組み

```
毎日 午前9時（平日）
    ↓
JPX公式XLSから銘柄一覧を取得
    ↓
Yahoo Finance Japanから時価総額・決算月を取得
    ↓
東証 監理ポスト・整理ポスト情報を取得
    ↓
上場維持基準と比較して危険・注意銘柄を抽出
    ↓
docs/index.html を自動更新（GitHub Pages）
```

## セットアップ方法

### 1. このリポジトリをFork

GitHubで「Fork」ボタンをクリックしてください。

### 2. GitHub Pagesを有効化

1. リポジトリの **Settings** → **Pages**
2. Source: `Deploy from a branch`
3. Branch: `main` / `docs`
4. Save

### 3. 初回実行

1. **Actions** タブ → **上場維持基準 監視サイト 自動更新**
2. **Run workflow** をクリック
3. 数分後に `https://あなたのユーザー名.github.io/tse-watch/` で公開されます。

以後は毎営業日の午前9時（日本時間）に自動更新されます。
